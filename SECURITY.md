# Security Policy

## Supported version

Only the version currently deployed from the default branch receives security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the email address listed in the application's
Impressum. Do not include real user data, credentials, or destructive proof-of-concept material.

Include the affected endpoint or component, reproduction steps, the expected impact, and any safe
mitigation you identified. Reports will be acknowledged as soon as practical. This personal project
does not currently operate a paid bug-bounty program.

Please do not open a public issue until the vulnerability has been fixed or disclosure has been
coordinated.
